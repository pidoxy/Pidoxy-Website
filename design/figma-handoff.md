## Design system and checks

The file includes Fraunces/Inter typography with IBM Plex Mono metadata, 43 scoped variables with CSS code syntax, 12 local text styles, and reusable buttons, badges, navigation, publication rows, and feature cards. Button variants include Default, Hover, and Focus.

There are 134 prototype-connected nodes. Core navigation and work actions connect the desktop or mobile screens; paper and product actions use the supplied public URLs. This is a design prototype, not an implemented website. Some secondary footer labels are visual only; the mobile archive links lead to existing website pages.

The layout audit found no overflowing direct children in auto-layout containers across the 15 screen/menu frames. Rendered screens were reviewed, including mobile publication wrapping. Text, vectors, and layout hierarchy are editable; only portrait photography uses image fills. No complete-screen raster is used as a design layer.

AidCare imagery is an editable interface study, labeled accordingly. It should be replaced or reconciled with approved product imagery before implementation. The research graphic illustrates a question rather than experimental results. Publication status and author order come from the current portfolio.
